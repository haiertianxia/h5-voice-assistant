## 二、技术选型

### 2.1 前端技术选型

| 技术 | 选型 | 理由 |
|------|------|------|
| **框架** | 原生 HTML/CSS/JS | 无需构建工具，体积小，加载快 |
| **样式** | CSS Variables + 原生 CSS | 主题色统一，无依赖 |
| **图标** | 内联 SVG | 无 CDN 依赖，离线可用 |
| **字体** | Google Fonts (Geist + Noto Sans SC) | 加载即缓存 |
| **录音** | MediaRecorder API | 浏览器原生，无需 SDK |
| **语音识别** | Web Speech API → AssemblyAI | 优先浏览器免费，失败后服务端兜底 |
| **语音合成** | 水星 TTS → Web Speech API | 优先高质量服务端合成 |
| **可视化** | Canvas API | 波形绘制，无依赖 |
| **设置存储** | localStorage | 无服务端存储需求 |

### 2.2 后端技术选型

| 技术 | 选型 | 理由 |
|------|------|------|
| **运行时** | Node.js 18+ | 原生 ES Module 支持，成熟稳定 |
| **框架** | Express.js | 轻量，生态丰富，学习成本低 |
| **语言** | JavaScript (ES2022) | 前后端统一语言，减少上下文切换 |
| **音频上传** | Multer (memoryStorage) | 接收浏览器上传，不写磁盘直接转 |
| **HTTP 客户端** | node-fetch v3 | 兼容浏览器 fetch API |
| **ID 生成** | uuid v9 | 临时文件名，无序不暴露信息 |
| **配置** | dotenv | 环境变量与代码分离 |
| **加密** | TLS (Nginx 终止) | HTTPS 保护传输安全 |

### 2.3 外部服务选型

| 服务 | 用途 | 费用 | 备选方案 |
|------|------|------|---------|
| **Volcengine ARK** | LLM 对话 | 按 token 计费 | OpenAI API / Claude API |
| **ByteDance TTS** | 语音合成 | 按请求计费 | Web Speech API (免费) |
| **AssemblyAI** | 语音识别 | 按分钟计费 | Web Speech API (免费) |

### 4.3 Nginx 配置要点

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;

    # 静态资源（Node.js 服务）
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 音频文件（直接从文件系统读取，不走 Node.js）
    location /uploads/ {
        alias /path/to/server/uploads/;
        add_header Cache-Control "public, max-age=3600";
    }

    # 健康检查（Node.js 处理）
    location /api/health {
        proxy_pass http://127.0.0.1:3000;
    }
}
```

## 六、安全设计

| 威胁 | 应对方案 |
|------|---------|
| API Key 泄露 | Key 只存在于后端 `.env`，前端完全不接触 |
| CORS 劫持 | 生产环境指定明确 origin，不使用通配符 `*` |
| 频率滥用 | 内存限流：30 req/min/IP |
| 文件上传攻击 | Multer 强制 10MB 上限，后端验证 Content-Type |
| SSRF | 外部 API 调用限制内网地址（白名单） |
| 音频文件遍历 | `/uploads/` 路径不暴露文件列表，只能访问已知 UUID |
| HTTPS 中间人 | 严格 TLS 1.2+，生产环境强制 HTTPS |
| 日志泄露 | 敏感字段（key、token）在日志中脱敏输出 |


### 7.2 日志级别

| 级别 | 场景 |
|------|------|
| `console.error` | API 调用失败、超时、权限错误 |
| `console.warn` | 服务降级（key 未配置）、文件清理失败 |
| `console.log` | TTS 生成成功（不含内容）、服务器启动 |
| 静默 | 正常对话流程（无用户内容日志） |

### 7.3 启动检查清单

- [ ] `.env` 文件存在，`ARK_API_KEY` 已填写
- [ ] HTTPS 证书已配置（生产环境）
- [ ] `server/uploads/` 目录存在且可写
- [ ] 端口 3000 未被占用
- [ ] 外部网络可访问 ARK/TTS/AssemblyAI 端点
