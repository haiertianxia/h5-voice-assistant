### 1.2 关键方法时序

```mermaid
sequenceDiagram
    participant App as VoiceAssistant
    participant Rec as AudioRecorder
    participant Canvas as Canvas DOM

    App->>Rec: requestPermission()
    Rec->>navigator: getUserMedia({audio:true})
    navigator-->>Rec: MediaStream
    Rec-->>App: true

    App->>Rec: start()
    Note over Rec: 创建 AudioContext<br/>MediaRecorder.start(100ms)<br/>_startWaveform()<br/>_resetSilenceTimer()

    loop 静默检测
        Rec->>Rec: _checkAudioLevel()
        Note over Rec: RMS > 0.01<br/>→ _resetSilenceTimer()
        Note over Rec: 3s无声音<br/>→ onSilence()
    end

    App->>Rec: stop()
    Note over Rec: 返回 Promise
    Rec->>Rec: mediaRecorder.stop()
    Rec->>Rec: new Blob(chunks, audio/webm)
    Rec->>Rec: _cleanup()
    Rec-->>App: Blob
```

## 三、后端服务详细

### 3.1 ark.js — chat(text) 流程

```mermaid
sequenceDiagram
    participant Router as chat.js
    participant Ark as ark.js
    participant ARK as Volcengine ARK API

    Router->>Ark: chat(text)
    Note over Ark: 校验 ARK_API_KEY
    Ark->>Ark: AbortController + timeout(15s)
    Ark->>ARK: POST /chat/completions<br/>{model, messages, max_tokens, temperature}
    ARK-->>Ark: {choices:[{message:{content}}]}
    Ark-->>Router: reply.trim()

    alt 超时
        Ark->>Ark: controller.abort()
        Note over Ark: throw Error(ARK API timed out after 15s)
    end

    alt 非200
        Ark->>Ark: throw Error(ARK API error {status})
    end

    alt 空响应
        Ark->>Ark: throw Error(Empty response)
    end
```

### 3.2 tts.js — textToSpeech 流程

```mermaid
sequenceDiagram
    participant Router as tts.js
    participant TTS as tts.js service
    participant TTS_API as ByteDance TTS

    Router->>TTS: textToSpeech(text, speed)
    alt TTS_API_KEY 未配置
        TTS-->>Router: null
    end

    TTS->>TTS: AbortController + timeout(10s)
    TTS->>TTS_API: POST /api/v1/tts
    TTS_API-->>TTS: audio/mp3 buffer

    alt 非200 或 JSON响应
        TTS-->>TTS: throw Error(TTS API error)
    end

    alt Content-Type 不是 audio
        TTS-->>TTS: throw Error(Unexpected content-type)
    end

    TTS->>TTS: Buffer.from(arrayBuffer)
    TTS->>fs: writeFileSync(uploads/{uuid}.mp3)
    TTS-->>Router: /uploads/{uuid}.mp3
```

### 3.3 stt.js — POST /api/stt 流程

```mermaid
sequenceDiagram
    participant Client as 浏览器
    participant STT as stt.js
    participant AA as AssemblyAI

    Client->>STT: POST /api/stt<br/>multipart audio/webm (≤10MB)

    STT->>STT: AbortController + timeout(45s)
    STT->>AA: POST /v2/upload
    AA-->>STT: {upload_url}
    STT->>AA: POST /v2/transcript<br/>{audio_url, language_code:zh, speech_model:universal}
    AA-->>STT: {id: transcript_id}

    loop Polling (30次，每次1s)
        STT->>AA: GET /v2/transcript/{id}
        AA-->>STT: {status}
        alt status === 'completed'
            Note over STT: text = statusData.text
        end
        alt status === 'error'
            Note over STT: break
        end
    end

    alt 成功
        STT-->>Client: {text}
    else 超时/失败
        STT-->>Client: 504 {error}
    end
```

### 3.4 RateLimiter 流程

```mermaid
flowchart LR
    subgraph 请求["请求进来"]
        R["req.ip"]
    end

    subgraph 检查["RateLimiter 检查"]
        E{key不存在<br/>或已过期?}
        C{count > 30?}
        OK["next()"]
        ERR["429 + Retry-After"]
    end

    R --> E
    E -->|"是"| RESET["count=1<br/>resetAt=now+60s"]
    E -->|"否"| C
    RESET --> OK
    C -->|"否"| INC["count++"]
    C -->|"是"| ERR
    INC --> OK
```
