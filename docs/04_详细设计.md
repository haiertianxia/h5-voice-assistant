## 一、模块详细设计

### 1.1 AudioRecorder 详细

requestPermission: Promise<boolean>
  navigator.mediaDevices.getUserMedia({audio:true, video:false})
  保存 stream 引用，供 start() 使用
  返回 true/false

start: boolean
  前置: stream 已存在（requestPermission 后）
  创建 AudioContext; analyser.fftSize = 256
  mediaRecorder = new MediaRecorder(stream)
  mediaRecorder.start(100)  每100ms触发一次
  isRecording = true
  _startWaveform()
  _resetSilenceTimer()
  maxDurTimer = setTimeout(60000, onSilence)
  返回 true

stop: Promise<Blob|null>
  返回 Promise
  mediaRecorder.onstop = () => { Blob chunks {type:audio/webm}; _cleanup(); resolve(blob) }
  mediaRecorder.stop()
  注意: stop() 是异步的，caller 必须 await

cancel: void
  if(mediaRecorder.state === recording) mediaRecorder.stop()
  _cleanup()

cleanup: void
  isRecording = false; _stopWaveform()
  clearTimeout(silenceTimer, maxDurTimer)
  audioContext?.close(); stream?.getTracks().forEach(t => t.stop())

checkAudioLevel: number (0-1)
  analyser.getByteTimeDomainData(buf)
  RMS = sqrt(sum((buf[i]-128)/128)^2 / buf.length)
  if RMS > 0.01 -> resetSilenceTimer()
  返回 RMS

resetSilenceTimer: void
  clearTimeout(silenceTimer)
  silenceTimer = setTimeout(onSilence, 3000)

### 1.2 AudioPlayer 详细

speak(text, onProgress): Promise<void>
  if(!window.speechSynthesis) return
  if(_ttsSource === server) return (由 caller 用 play() 处理)
  估算时长: (text.length / 5) / this.rate 秒
  startTime = Date.now()
  requestAnimationFrame updateProgress loop
  speechSynthesis.getVoices() -> 查找 zh 语音
  utt = new SpeechSynthesisUtterance(text)
  utt.lang = zh-CN; utt.rate = this.rate; utt.volume = this.volume
  utt.onend -> _speaking=false; onProgress(pct=1)
  utt.onerror -> _speaking=false
  speechSynthesis.speak(utt)

play(url, onProgress): Promise<void>
  stop()
  audio.src = url; audio.play().catch(()=>{})

stop: void
  speechSynthesis.cancel(); audio.pause(); audio.src = reset

### 1.3 VoiceAssistant 详细

_startRecording: Promise<void>
  if(!recorder.stream)
    granted = await recorder.requestPermission()
    if(!granted) { showToast + permissionHint; return }
  recorder.start()
  recorder.onSilence = _stopRecording (闭包引用)

_stopRecording: Promise<void>
  blob = await recorder.stop() 必须 await
  if(!blob || blob.size < 500) { resetState; return }
  text = await serverSTT(blob)
  if(!text?.trim()) { resetState; return }
  await chat(text.trim())

_serverSTT(blob): Promise<string|null>
  FormData.append(audio, blob, recording.webm)
  fetch /api/stt POST body=formData
  if(!res.ok) return null
  return res.json().text

_chat(text): Promise<void>
  fetch /api/chat {text, voiceSpeed}
  d = await r.json()
  await showAIReply(d.reply, d.audioUrl)

_showAIReply(text, audioUrl): Promise<void>
  await typewriter(p, text)
  if(!settings.muted)
    await player.speak(text, progress => ui.updateAudioProgress(msgId, progress))

_typewriter(el, text): Promise<void>
  el.textContent = reset
  for ch in text: el.textContent += ch; await sleep(28ms)

## 二、后端服务详细

### 2.1 ark.js

AbortController + setTimeout(15000)
- 成功: clearTimeout + process response
- 失败: clearTimeout + throw
- 超时: AbortError -> throw timed out message

响应处理:
- !response.ok -> throw Error(ARK API error status: text)
- !data.choices.0.message.content -> throw Error(Empty response)
- 返回 content.trim()

### 2.2 tts.js

响应验证 (关键):
- response.ok === false -> throw Error
- contentType includes application/json -> throw Error(detail)
- !contentType includes audio && !contentType includes octet -> throw Error
- buffer = Buffer.from(await response.arrayBuffer())
- 文件名: uuidv4() + .mp3

cleanupOldFiles:
- 启动时调用
- fs.readdirSync(uploads/)
- for each .mp3: if now-mtimeMs > 3600000 -> unlinkSync

### 2.3 stt.js

Polling 最多 30次，每次 1000ms
- status === completed -> text = statusData.text
- status === error -> console.error + break
- 全部失败 -> 504

### 2.4 RateLimiter

TTL 清理: setInterval(5min) 遍历删除过期条目
限制: 60s 窗口内 30 请求

## 三、接口详细规格

### 3.1 POST /api/chat

Request: Content-Type application/json
Body: text string (1-2000), voiceSpeed number (optional, default 1.0)

Response 200: reply string, audioUrl string|null
Response 400: error text is required
Response 413: error text too long (max 2000 chars)
Response 429: error, retryAfter number
Response 500: error 处理失败, detail string
Response 503: error (ARK_API_KEY not set)

### 3.2 POST /api/tts

Request: text string, voiceSpeed optional
Response 200: audioUrl string (MP3 URL)
Response 503: error TTS not available, useWebSpeech true

### 3.3 POST /api/stt

Request: multipart/form-data, field=audio, audio/webm, max 10MB
Response 200: text string (识别文字)
Response 400: error no audio file
Response 413: error File too large
Response 429: error, retryAfter number
Response 502: error Audio upload failed or Transcription start failed, detail
Response 504: error Transcription timeout or failed
