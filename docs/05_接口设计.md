# H5 Voice Assistant — 接口设计（API Reference）

版本：v1.1 | 日期：2026-05-14

## 一、接口概览

| 方法 | 路径 | 限流 | 说明 |
|------|------|------|------|
| GET | /api/health | 否 | 健康检查 |
| POST | /api/chat | 30/min/IP | LLM 对话 |
| POST | /api/tts | 30/min/IP | 文字转语音 |
| POST | /api/stt | 30/min/IP | 语音转文字 |

## 二、通用规范

### 2.1 请求编码
- Content-Type: application/json 或 multipart/form-data（见各接口）
- 字符编码: UTF-8

### 2.2 通用错误响应

状态码 400/413/429/500/503:
{
  "error": "错误描述",
  "detail": "详细错误信息（可选，仅供调试）"
}

状态码 429 额外字段:
{
  "error": "请求过于频繁，请稍后再试",
  "retryAfter": 30  // 秒
}

### 2.3 限流说明
- 窗口: 60 秒
- 限制: 同一 IP 在 60 秒内最多 30 次请求
- 超限: 返回 429，响应头包含 Retry-After

## 三、接口详情

### GET /api/health

健康检查，无需认证，返回各外部服务配置状态。

Request:
  curl https://api.example.com/api/health

Response 200:
{
  "status": "ok",
  "ark": true,
  "tts": false,
  "stt": false,
  "time": "2026-05-14T07:30:00.000Z"
}

字段说明:
- status: 固定 "ok"
- ark: ARK_API_KEY 是否已配置
- tts: TTS_API_KEY 是否已配置（false 则前端使用浏览器 TTS）
- stt: ASSEMBLYAI_API_KEY 是否已配置（false 则前端使用浏览器 STT）
- time: 服务器当前时间（ISO 8601）

---

### POST /api/chat

发送文字给 LLM，获取 AI 回复文字及可选音频 URL。

Request:
  curl -X POST https://api.example.com/api/chat \
    -H "Content-Type: application/json" \
    -d '{"text":"你好，请介绍一下你自己","voiceSpeed":1.0}'

Request Body:
  text:       string   必填，用户说的话，1-2000 字符
  voiceSpeed: number   选填，语速倍率，0.5-2.0，默认 1.0

Response 200:
{
  "reply": "你好！我是你的语音助手，很高兴认识你~",
  "audioUrl": "/uploads/a1b2c3d4.mp3"
}

audioUrl 说明:
- 当 TTS_API_KEY 已配置且生成成功时: MP3 文件 URL（相对路径）
- 当 TTS_API_KEY 未配置或生成失败时: null

Response 400 (参数错误):
  {"error": "text is required"}

Response 413 (输入过长):
  {"error": "text too long (max 2000 chars)"}

Response 429 (频率超限):
  {"error": "请求过于频繁，请稍后再试", "retryAfter": 30}

Response 500 (服务端错误):
  {"error": "处理失败，请稍后重试", "detail": "..."}

Response 503 (服务不可用):
  {"error": "处理失败，请稍后重试", "detail": "ARK_API_KEY environment variable is not set"}

---

### POST /api/tts

将文字转换为语音，返回 MP3 文件 URL。

Request:
  curl -X POST https://api.example.com/api/tts \
    -H "Content-Type: application/json" \
    -d '{"text":"你好世界","voiceSpeed":1.0}'

Request Body:
  text:       string   必填，待合成文字
  voiceSpeed: number   选填，语速倍率，默认 1.0

Response 200:
{
  "audioUrl": "/uploads/e5f6g7h8.mp3"
}

audioUrl: 服务器上生成的 MP3 文件相对路径，有效期 1 小时

Response 400:
  {"error": "text is required"}

Response 413:
  {"error": "text too long"}

Response 503:
  {"error": "TTS not available", "useWebSpeech": true}

---

### POST /api/stt

上传音频文件，识别为文字。

Request:
  curl -X POST https://api.example.com/api/stt \
    -F "audio=@recording.webm"

Request:
  Content-Type: multipart/form-data
  Field: audio
  文件格式: audio/webm（推荐，含 opus 编码）
  最大大小: 10 MB

Response 200:
{
  "text": "用户说的话被识别为这段文字"
}

Response 400:
  {"error": "no audio file"}

Response 413:
  {"error": "File too large"}

Response 429:
  {"error": "请求过于频繁，请稍后再试", "retryAfter": 30}

Response 502 (第三方服务错误):
  {"error": "Audio upload failed", "detail": "..."}
  或
  {"error": "Transcription start failed", "detail": "..."}

Response 504 (转录超时):
  {"error": "Transcription timeout or failed"}

## 四、音频文件规范

上传文件（STT）:
  格式: audio/webm (opus codec)
  MIME: audio/webm;codecs=opus
  最大: 10MB

生成文件（TTS）:
  格式: MP3
  路径: /uploads/{uuidv4}.mp3
  生命周期: 生成后 1 小时内可访问
  清理策略: 启动时自动删除 1 小时前文件

## 五、前端降级策略

当后端服务不可用时，前端自动降级:

| 后端状态 | 前端行为 |
|---------|---------|
| ARK_API_KEY 未配置 | POST /api/chat 返回 503，前端显示文字提示 |
| TTS_API_KEY 未配置 | audioUrl=null，前端使用浏览器 Web Speech Synthesis |
| ASSEMBLYAI_API_KEY 未配置 | STT 请求 503，前端使用浏览器 Web Speech API |
| /api/chat 网络失败 | 前端 Toast: 服务不可用，请检查网络 |
| /api/stt 网络失败 | 前端 Toast: 没听清楚，请重试 |

浏览器 Web Speech API 可用性检测:
  STT: !!(window.SpeechRecognition || window.webkitSpeechRecognition)
  TTS: !!(window.speechSynthesis && speechSynthesis.getVoices().length > 0)
