# H5 Voice Assistant — 概要设计（HLD）

版本：v1.1 | 日期：2026-05-14

## 一、系统模块划分

```
H5 Voice Assistant
├── 前端 (Browser)
│   ├── VoiceAssistant (主控制器)
│   │   ├── AudioRecorder (录音 + 波形)
│   │   ├── AudioPlayer (播放 + 进度)
│   │   └── UIController (DOM 操作)
│   └── localStorage: vaSettings {volume, speed, muted, ttsSource}
│
└── 后端 (Node.js / Express)
    ├── RateLimiter (30 req/min/IP)
    ├── Routes
    │   ├── chat.js → ARK 大模型对话
    │   ├── tts.js  → 水星 TTS 语音合成
    │   └── stt.js  → AssemblyAI STT
    └── Services
        ├── ark.js  (15s 超时)
        ├── tts.js  (10s 超时, 文件清理)
        └── stt.js  (45s 超时, polling)
```

## 二、类图（Class Diagram）

### 2.1 前端核心类关系

```
VoiceAssistant (主控制器)
├── state: 'idle'|'recording'|'processing'
├── settings: {volume, speed, muted, ttsSource}
├── recorder: AudioRecorder  [组合]
├── player:   AudioPlayer     [组合]
└── ui:       UIController    [组合]

AudioRecorder
├── stream: MediaStream|null
├── mediaRecorder: MediaRecorder|null
├── audioContext: AudioContext|null
├── analyser: AnalyserNode|null
├── isRecording: boolean
├── silenceTimer: number
├── maxDurTimer: number       (60s 最大录音)
├── onSilence: Function|null
└── animationId: number

AudioPlayer
├── audio: HTMLAudioElement
├── rate: number
├── volume: number
├── _speaking: boolean
├── _utterance: SpeechSynthesisUtterance|null
└── _ttsSource: 'web'|'server'

UIController
└── app: VoiceAssistant (反向引用)
```

### 2.2 后端模块

```
server/index.js
├── apiLimiter: RateLimiter
├── HTTPS/HTTP 自适应启动
└── 静态文件服务 /uploads

RateLimiter (server/utils/ratelimit.js)
├── store: Map<ip, {count, resetAt}>
├── WINDOW_MS = 60000
├── MAX_REQUESTS = 30
└── 定时清理过期条目

chat.js (路由)
├── POST /
├── 输入: {text, voiceSpeed}
├── 输出: {reply, audioUrl}
└── 错误: 400/413/429/500/503

ark.js (服务)
├── chat(text): Promise<string>
├── TIMEOUT_MS = 15000 (AbortController)
├── SYSTEM_PROMPT: AI 系统提示词
└── 错误: 超时/401/非200

tts.js (服务)
├── textToSpeech(text, speed): Promise<string|null>
├── TIMEOUT_MS = 10000
├── 启动时清理 1h+ 旧文件
├── 验证 Content-Type (audio/* 或 octet-stream)
└── 错误: 超时/API error/JSON response

stt.js (路由)
├── POST /
├── 输入: multipart audio/webm (≤10MB)
├── 输出: {text}
├── 流程: upload → transcript → poll (30次,每次1s)
└── 错误: 400/413/429/502/504
```

## 三、组件状态机

### 3.1 VoiceAssistant 状态转换

```
  [长按120ms]      [松手/超时]      [成功完成]
idle ──────► recording ──────► processing ──────► idle
                  │                   │
                  │ [取消/离开]       │ [_resetState]
                  └───────────────────┘
```

状态说明:
- idle: 等待用户长按，orb 显示麦克风图标
- recording: 正在录音，orb 变色+波形，onSilence 监听中
- processing: 已停止录音，STT/Chat/TTS 处理中

### 3.2 Orb 视觉状态

| 状态 | CSS 类 | 图标 | 动画 |
|------|--------|------|------|
| idle | orb-idle | 麦克风 | 呼吸光晕 |
| recording | orb-recording | 隐藏 | Accent色 + 扩散ring + 波形 |
| processing | orb-processing | 加载旋转 | orb-icon-loading 显示 |

### 3.3 录音静默检测

- 阈值: RMS > 0.01 视为有声
- 超时: 3 秒无声音 → _stopRecording()
- 最大时长: 60 秒硬性上限（setTimeout）

## 四、数据模型

### 4.1 前端状态

Settings (localStorage['vaSettings']):
- volume: number (0-100, 默认 80)
- speed: number (50-200, 默认 100)
- muted: boolean (默认 false)
- ttsSource: 'web'|'server' (默认 'web')

### 4.2 后端 API 模型

POST /api/chat
- Request: {text: string (1-2000), voiceSpeed: number (可选, 默认1.0)}
- Response: {reply: string, audioUrl: string|null}
- Errors: 400(text required), 413(too long), 429(rate limit), 500, 503

POST /api/stt
- Request: multipart/form-data, field='audio', audio/webm, ≤10MB
- Response: {text: string}
- Errors: 400(no file), 413(too large), 429, 502, 504

POST /api/tts
- Request: {text: string, voiceSpeed: number (可选)}
- Response: {audioUrl: string}
- Errors: 400, 413, 429, 500, 503

GET /api/health
- Response: {status:'ok', ark:bool, tts:bool, stt:bool, time:ISO8601}

## 五、路由矩阵

| 方法 | 路径 | 限流 | 说明 |
|------|------|------|------|
| GET | / | - | 302 → /index.html |
| GET | /index.html | - | 静态 HTML |
| GET | /api/health | - | 健康检查 |
| POST | /api/chat | 30/min | LLM 对话 |
| POST | /api/tts | 30/min | 语音合成 |
| POST | /api/stt | 30/min | 语音识别 |

## 六、错误处理策略

前端:
- fetch() 失败 → Toast "服务不可用，请检查网络"
- r.ok === false → Toast err.error || "API错误"
- TTS 返回 null → 静默降级（用浏览器 Web Speech）
- STT 返回 null/空 → Toast "没听清楚，请再说一次~"

后端:
- 400 Bad Request → 参数校验失败
- 413 Payload Too Large → 文件超过 10MB
- 429 Too Many Requests → Retry-After 头
- 500 Internal Error → 记录日志，返回通用错误
- 503 Service Unavailable → ARK_API_KEY 未配置

降级链:
- TTS: 水星TTS → 浏览器 Web Speech Synthesis
- STT: 浏览器 Web Speech API → AssemblyAI
- 全部不可用: 仅显示文字回复

## 七、非功能性指标

| 指标 | 目标 |
|------|------|
| 可用性 | 99%（外部 API 故障时有降级）|
| 响应时间 | p95 < 5s（含 ARK + TTS）|
| 页面大小 | gzip 后 < 100KB |
| 最大并发 | ~200（受外部 API 限制）|
| 音频文件清理 | 启动时删除 1h+ 前文件 |
