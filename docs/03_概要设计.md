## 三、组件状态机（State Diagram）

### 3.1 VoiceAssistant 主状态机

```mermaid
stateDiagram-v2
    [*] --> idle: 初始化
    idle --> recording: _startRecording()
    recording --> processing: _stopRecording()
    processing --> idle: _showAIReply() 完成
    processing --> idle: _resetState() 错误
    recording --> idle: _cancelRecording()
    recording --> recording: 3s静默 → _stopRecording()
    recording --> recording: 60s超时 → _stopRecording()

    state idle {
        [*] --> 等待用户长按
    }

    state recording {
        [*] --> 录音中
        录音中 --> orb变色
        orb变色 --> 波形动画
        波形动画 --> 静默检测中
    }

    state processing {
        [*] --> STT识别中
        STT识别中 --> Chat对话中
        Chat对话中 --> 打字机动画
    }
```
